- Sou estudante de Sistemas de Informação e atualmente, estou aprofundando meus estudos em versionamento de 
código, desenvolvimento mobile com Android Studio, e no desenvolvimento de APIs. Também tenho conhecimentos

as coisas funcionam, pois isso amplia minha visão e me permite otimizar processos de forma mais eficiente. Sou 
apaixonado por lógica e sempre busco soluções criativas para os desafios que surgem.
